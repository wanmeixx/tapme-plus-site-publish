TapMe.plus now has a web build for quick play in a browser. The web version keeps the same core rule as the mobile game: tap a number to add 1, connect three or more matching numbers, merge them into the target tile, and use the resulting drops to set up the next chain.

The first browser launch downloads the Godot runtime and game package. After that, the browser can cache the game resources, so later visits should usually start faster.

Use the dedicated web game page at [web.tapme.plus](https://web.tapme.plus), or start from the TapMe.plus homepage.
