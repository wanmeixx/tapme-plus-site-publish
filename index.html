TapMe.plus

A fast number merge puzzle built around one simple move: tap a tile to add 1, connect three or more matching numbers, and watch the board chain upward.

Play Web Version Play on this page

The web version downloads the Godot game package on first launch. Later visits are cached by the browser.

One-tap puzzle flow

Each tap increases a number by one. If three or more equal numbers connect horizontally or vertically, they merge into the target tile and upgrade.

Chain reactions

Merges drop the board, refill tiles, and can trigger more merges. The best runs come from planning where the next chain should land.

Three modes

Timed, Infinite, and Rush modes keep the same clean core rule while changing pressure, scoring rhythm, and session length.
