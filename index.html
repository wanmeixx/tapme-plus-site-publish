TapMe.plus

A polished number merge puzzle for short portrait sessions: tap to add 1, connect matching numbers, and build chain reactions without losing the clean one-thumb flow.

Play Web Version Read Gameplay Guide

The official web build is available now. The iPhone and iPad release is prepared around privacy-first local play and optional Apple Game Center leaderboards.

One-tap rules

Tap any tile to increase its number by one. When three or more equal numbers touch horizontally or vertically, they merge into the tapped target.

Readable chains

Every merge drops the board, refills the grid, and can trigger follow-up merges. The goal is to shape where the next upgrade lands.

Built for sessions

Timed, Infinite, and Rush modes use the same core board while changing the pressure curve, scoring rhythm, and replay goal.

How it plays

TapMe.plus keeps the rule set compact so the board state stays readable even when the chain reactions become large.

Tap to raise a tile

Choose the tile that should become the merge target. The tapped number increases by one.

Connect three or more

Matching numbers connected up, down, left, or right merge into the target tile and upgrade.

Use the drop

After a merge, tiles fall and new tiles fill the board. Strong moves set up the next automatic chain.

iPhone first, iPad ready

The layout is tuned for portrait play, safe areas, and repeated one-thumb sessions. On iPad, the board scales up while keeping controls calm and readable.
