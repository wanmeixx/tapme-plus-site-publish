## Web game loading

The web version downloads a Godot WebAssembly runtime and game package. The first launch can be slower than a normal website page, especially on mobile networks. Later visits are usually faster because the browser may cache game resources.

If the web game does not load:

- open [https://web.tapme.plus/](https://web.tapme.plus/) directly;
- refresh the page once after the first failed load;
- try Safari, Chrome, Edge, or Firefox;
- disable aggressive content blockers for `web.tapme.plus`;
- check whether your network blocks large WebAssembly downloads;
- try another network if the page loads but the game package stalls;
- update your browser and operating system if WebAssembly support is outdated.

## iPhone and iPad

If you are playing on iPhone or iPad:

- make sure Low Power Mode is not severely throttling browser performance;
- keep enough free storage for the browser or app to cache resources;
- rotate back to portrait if the layout feels cramped;
- close heavy background apps if animation becomes unstable;
- sign in to Apple Game Center only if you want leaderboard features.

## Gameplay basics

Tap a tile to add 1. When three or more matching numbers connect horizontally or vertically, they merge into the tapped target tile and upgrade. After a merge, tiles drop and new tiles refill the board.

Useful notes:

- The timer starts after your first valid move.
- During merge, drop, and refill animations, input is briefly locked.
- Chain reactions can continue after a merge if new matches are formed.
- Infinite mode focuses on long-form score building rather than a fixed countdown.
- Shapes are optional visual hints and do not change the number rules.

## Common questions

### Why is the first web load slow?

The browser needs to download the game runtime and package. After that, browser caching usually makes repeat visits faster.

### Will clearing browser data delete my progress?

For the web version, yes, clearing site data may remove local scores, preferences, and progress stored by the browser.

### Do I need an account?

No TapMe.plus account is required for the first release. Apple Game Center may be used optionally on Apple devices for platform leaderboard features.

### Does the game track me?

The first release does not use third-party analytics or advertising tracking. Read the [Privacy Policy](/privacy/) for details.

### Where do I report a bug?

Send an email to [support@tapme.plus](mailto:support@tapme.plus). Include:

- device and operating system;
- browser or app version;
- game mode;
- steps to reproduce the issue;
- screenshot or screen recording if possible;
- approximate time when the issue happened.
