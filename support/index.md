## Web game loading

The web version downloads a Godot WebAssembly runtime and game package on first launch. The first load can be slower than a normal website page. Later visits are usually faster because the browser can cache game resources.

If the web game does not load:

- Refresh the page once.
- Try a modern browser such as Safari, Chrome, Edge, or Firefox.
- Disable aggressive content blockers for `web.tapme.plus`.
- Check that your network allows large WebAssembly downloads.

## Gameplay

Tap a tile to add 1. When three or more matching numbers connect horizontally or vertically, they merge into the tapped target tile and upgrade. After a merge, tiles drop and new tiles refill the board.

## Privacy and accounts

The first release does not require a TapMe.plus account, does not show ads, and does not track users. Optional Apple Game Center leaderboard activity is handled by Apple.

Read the [privacy policy](/privacy/) for details.
